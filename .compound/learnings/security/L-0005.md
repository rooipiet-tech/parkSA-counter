statement: Any CSV/spreadsheet export of user-controlled text is a formula-injection vector: values starting with =, +, -, @, or tab/CR execute when opened in Excel/Sheets. This compounds when the source field is remotely writable (e.g. an anon-key-writable RLS table), so an attacker can plant a formula without ever touching the exporting device. Prefix-guard (quote/space-prefix) any field beginning with a formula character, or constrain the input charset at write time.
evidence: RS-01 major: csvField() had no formula-prefix guard; provider_name free text flowed into CSV and was plantable remotely via anon-key provider rename. Passed all functional tests (AC-19 header stayed byte-identical because escaping applies to values only).
catch_next_time: Security lens: for every CSV/XLSX export, verify a formula-prefix guard on all user/remote-sourced fields, and check who can write the source field (anon-writable RLS raises severity). Add a test exporting a field named '=cmd()' and assert the cell is neutralized.
